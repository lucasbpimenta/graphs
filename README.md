# Consortium network of offshore oil and gas blocks in Brazil

Code and data for the paper "Centrality and Structural Change in the Consortium Network of Offshore Oil and Gas Blocks in Brazil", by Lucas de Barros Pimenta and Renata R. Del-Vecchio (PPGEP, Universidade Federal Fluminense), and for its supplementary material.

The scripts harmonize public datasets of the Brazilian National Agency of Petroleum, Natural Gas and Biofuels (ANP), reconstruct the composition of each consortium at award, build the projected networks of economic groups and compute every table and figure of the paper and of the supplement.

## Contents

```
data/raw/         ANP datasets as downloaded (October 2026) and the list of preferential-right contracts
data/processed/   harmonized tables and every intermediate and final result (CSV, UTF-8)
scripts/          Python scripts, numbered in the order they must be run
figures/          figures of the paper, generated by scripts/12_figuras.py
```

`data/README.md` describes each file and the conventions of the harmonization (economic groups, regimes, reconstruction of the award composition).

The ANP updates the portfolio of contracts and the file of rights assignments regularly. The files in `data/raw/` are the versions used in the paper; a new download will give different numbers.

## Requirements

Python 3.10 and the packages in `requirements.txt`:

```
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## Running

From the repository root:

```
bash run_all.sh
```

or each script in turn, for example `.venv/bin/python scripts/01_base_harmonizada.py`. The null-model scripts (04, 13 and 14) take a few minutes each. All random procedures use fixed seeds, given at the top of each script.

Comments and variable names in the scripts are in Portuguese; the outputs keep the Portuguese column names described in `data/README.md`.

## Scripts and results

| Script | What it does | Used in |
|---|---|---|
| `00_setores_opc.py` | Extracts the sector of the blocks awarded in cycles 4 and 5 of the Permanent Offer from the ANP judgment reports (the output is already in `data/raw/anp_opc/`) | Water depth classification |
| `01_base_harmonizada.py` | Reads the ANP files, standardizes company names and assigns each company to its economic group | Section 3.1 |
| `02_redes_regime.py` | Reconstructs the composition at award and builds the edge lists | Sections 3.2 and 3.3 |
| `03_centralidades.py` | Centrality measures and Spearman correlations | Tables 1 and 2, Sections 4.1 to 4.3 |
| `04_modelo_nulo.py` | Fixed degree sequence model of the bipartite graph (1,000 simulations) | Table 3, Section 4.4 |
| `07_persistencia.py` | Panel of pairs of groups in the offshore auctions and logit model of partner repetition | Section 4.4, Table S4 |
| `08_camadas.py` | Regimes as network layers, edge overlap, multiplex participation, consortia by water depth | Table 4, Section 4.5 |
| `09_arremate_atual.py` | Award network against current network: global measures, kept, lost and new edges, rank correlation | Table 5, Section 4.6 |
| `10_grafo_dirigido.py` | Directed graph from operators to non-operators | Table 6, Section 4.7 |
| `11_remocao.py` | Removal of Petrobras, robustness curves and preferential-right counterfactual | Table 7, Section 4.8 |
| `12_figuras.py` | Figures 1 to 4 | Figures 1 to 4 |
| `13_sobreposicao_nucleo.py` | Layer overlap against a layer-wise null model and persistence of the core | Sections 4.5 and 4.6 |
| `14_suplementar.py` | Erdős–Rényi and configuration benchmarks, onshore contrast, centralities of all groups | Tables S1 to S3 and S6 |
| `empresas.py`, `redes_mar.py` | Shared functions: company and group rules; offshore networks at award and today | |

## Data sources

All data are public ANP datasets, available at https://www.gov.br/anp/ (Dados abertos): the list of concessionaires by contract, the winning bids and blocks offered in Rounds 1 to 17, the approved rights assignments, and the Permanent Offer documents. The list of contracts in which Petrobras exercised its preferential right (`data/raw/preferencia_petrobras.csv`) was compiled by the authors from the resolutions of the National Energy Policy Council (CNPE) and the ANP auction minutes; the source of each row is in the column `fonte`.
